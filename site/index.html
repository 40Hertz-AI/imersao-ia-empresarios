Instalação

Deixe o computador pronto antes do dia.

São 4 passos e uma conferência. Escolha o seu sistema.

1

Assine o Claude Pro

Entre em claude.ai, crie a conta e assine o plano Pro. O plano gratuito não dá acesso ao Claude Code.

2

Instale o app do Claude

  1. Baixe o instalador em claude.com/download (versão Windows).
  2. Abra o arquivo baixado e siga a instalação.
  3. Abra o Claude pelo menu Iniciar e entre com a sua conta.

O Claude Code já vem dentro do app, na aba Code. Não precisa de terminal para usar.

3

Instale o Node.js

  1. Entre em nodejs.org e baixe a versão LTS.
  2. Abra o instalador e clique em Next até o fim, sem mudar nada.

Por quê: é o que instala as skills da aula e gera a apresentação em PowerPoint.

4

Instale o Git

  1. Entre em git-scm.com/install/windows e clique em Click here to download.
  2. Abra o instalador e clique em Next até o fim, sem mudar nada.

Por quê: as skills da aula ficam no GitHub, e é o Git que as baixa. No Windows, o Claude Code também usa o Git para rodar comandos. Não precisa criar conta no GitHub.

Confira se deu certo

  1. Aperte a tecla Windows, digite PowerShell e abra.
  2. Cole os dois comandos e aperte Enter:
node -v
git --version
Deu certo se aparecer um número de versão em cada linha (tipo v24... e git version 2...). Se aparecer "não é reconhecido", feche e abra o PowerShell de novo. Se continuar, reinicie o computador.
1

Assine o Claude Pro

Entre em claude.ai, crie a conta e assine o plano Pro. O plano gratuito não dá acesso ao Claude Code.

2

Instale o app do Claude

  1. Baixe o instalador em claude.com/download (versão Mac, serve para chip Intel e Apple).
  2. Abra o arquivo baixado e arraste o Claude para a pasta Aplicativos.
  3. Abra o Claude e entre com a sua conta.

O Claude Code já vem dentro do app, na aba Code. Não precisa de terminal para usar.

3

Instale o Node.js

  1. Entre em nodejs.org e baixe a versão LTS para macOS (o instalador .pkg).
  2. Abra o instalador e clique em Continuar até o fim.

Por quê: é o que instala as skills da aula e gera a apresentação em PowerPoint.

4

Instale o Git

  1. Abra o Terminal (Cmd + Espaço, digite "Terminal", Enter).
  2. Cole o comando abaixo e aperte Enter:
xcode-select --install
  1. Vai abrir uma janela da Apple. Clique em Instalar e espere terminar (pode levar alguns minutos).

Por quê: as skills da aula ficam no GitHub, e é o Git que as baixa. Esse comando instala o Git oficial da Apple. Se aparecer "already installed", já está pronto. Não precisa criar conta no GitHub.

Confira se deu certo

No Terminal, cole os dois comandos e aperte Enter:

node -v
git --version
Deu certo se aparecer um número de versão em cada linha (tipo v24... e git version 2...). Se aparecer "command not found", feche e abra o Terminal de novo.

Os dois últimos ajustes (Windows e Mac)

Chrome e conta Google pessoal

Tenha o Google Chrome e uma conta Google pessoal. Conta da empresa às vezes é bloqueada pelo administrador para conectar ferramentas.

Teste de 1 minuto

Abra o app do Claude → aba Code → escolha qualquer pasta → escreva "oi". Se ele responder, está pronto. Depois digite /skills: em "claude.ai sync" devem aparecer skill-creator e pdf.

No dia: instalar as skills

Você não precisa fazer isso antes. Na aula, todo mundo cola este texto no Claude Code junto, e ele roda os comandos.

Rode estes dois comandos no terminal e me avise quando terminar. Depois liste as skills instaladas.
1. npx -y skills add https://github.com/santanalc/imersao-ia-empresarios -g -a claude-code -s '*' -y
2. npx -y skills add https://github.com/anthropics/skills -s pptx -g -a claude-code -y

Depois feche e abra a conversa de novo e digite / para ver as skills.

Ajuda

Os tropeços mais comuns.

Se nada disso resolver, fale com a gente antes do dia.

Clico na aba Code e ele pede para assinar
A conta ainda está no plano gratuito. Assine o Pro em claude.ai, feche o app e abra de novo.
"node" ou "git" não é reconhecido
Feche e abra o PowerShell (ou o Terminal) depois de instalar. Se continuar, reinicie o computador. Se ainda assim não der, instale de novo sem mudar nenhuma opção.
Não consigo conectar a conta Google
Conta Google da empresa às vezes é bloqueada pelo administrador. Use a sua conta pessoal.
O computador é da empresa e não deixa instalar nada
Peça a liberação para a TI antes do dia, ou traga um computador pessoal. No dia, não dá tempo de resolver permissão de administrador.
Preciso saber programar?
Não. Você conversa com o Claude em português, e ele faz. Os textos de cada exercício ficam prontos para colar.
Dica que resolve muita coisa
Pergunte ao próprio Claude: "deu este erro, o que eu faço?" e cole a mensagem de erro.
