# /eli5 o que é margem de contribuição

> Gerado de verdade pelo Claude Code (modelo Opus) nesta pasta, com o prompt do passo, em 25/10/2026. **Dados fictícios de exemplo.** O seu resultado vai sair diferente nas palavras; o que importa é chegar no mesmo tipo de entrega.

**Você:**

```
/eli5 o que é margem de contribuição
```

**Claude:**

**Em uma frase:** margem de contribuição é o dinheiro que sobra de cada venda depois de pagar o que aquela venda gastou. Esse dinheiro ajuda a pagar as contas fixas da empresa e, depois delas, vira lucro.

**Pensa assim:** você vende limonada. Cada copo gasta limão, açúcar e o copo. O que sobra de cada copo vai para um cofrinho. Com o cofrinho você paga o aluguel da barraca, que custa o mesmo valor vendendo muito ou pouco.
*Onde a comparação falha:* numa empresa de verdade, separar o gasto que depende da venda do gasto que não depende nem sempre é tão claro.

**Como funciona, passo a passo:**
1. Você vende um produto por um preço.
2. Tira os custos variáveis, que são os que só existem porque você vendeu: matéria-prima, embalagem, frete, taxa do cartão.
3. O que sobra é a margem de contribuição daquele produto.
4. Some as margens de todas as vendas do mês.
5. Tire os custos fixos (aluguel, salários). Se sobrar dinheiro, é lucro. Se faltar, é prejuízo.

**Por que isso importa:** mostra quais produtos ou canais de venda pagam mais as contas. Um produto que vende muito mas deixa pouca margem pode render menos que outro que vende menos.

**Quer ir um nível acima?** Aprenda o **ponto de equilíbrio**, que é quanto você precisa vender no mês para a margem cobrir todos os custos fixos.
